Developer interface

Session authentication,
available through an API.

Register using JSON, authenticate through the standard form endpoint, and retrieve your account profile.

Method Endpoint Purpose
GET /api/csrf Obtain CSRF token and session
POST /api/register Create a member account
POST /login Authenticate using email and password form fields
GET /api/me Read your profile
POST /logout End your session

See the repository’s API guide for a complete example, including cookie and CSRF handling.
